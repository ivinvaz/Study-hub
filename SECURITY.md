# Política de Segurança
## Versões suportadas
Apenas a branch `main` recebe correções.
## Como relatar uma vulnerabilidade
Não abra uma issue pública. Use o relato privado de vulnerabilidades do
GitHub (aba Security > Report a vulnerability) ou envie mensagem pelo
LinkedIn: www.linkedin.com/in/vazivin.
## Dados pessoais publicados indevidamente
Se encontrar dado pessoal exposto no site, informe pelos mesmos canais
para que seja removido.
## Prazo de resposta
O mantenedor buscará responder em até 7 dias.
