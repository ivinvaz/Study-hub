# Contribuindo com o PortfolioHUB
Obrigado pelo interesse! Siga o fluxo abaixo.
1. Faça um fork do repositório.
2. Crie uma branch curta a partir da `main`:
 `git checkout -b feat/minha-melhoria`
3. Faça commits no padrão Conventional Commits:
 `git commit -m "feat: adiciona seção de certificados"`
4. Envie a branch: `git push origin feat/minha-melhoria`
5. Abra um Pull Request usando o template e vincule a issue (`Closes #n`).
6. Resolva todos os comentários da revisão antes do merge.
## Regras
- Não inclua senhas, tokens, chaves ou dados pessoais de terceiros.
- Mantenha os README.md atualizados.
- Seja respeitoso(a) em issues e revisões.
